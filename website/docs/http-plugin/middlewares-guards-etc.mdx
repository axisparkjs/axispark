# Middlewares, Guards, etc

AxiSpark.js has a powerful and flexible engine system that allows you to add custom logic to your application. This system is built for all Transport (RabbitMQ, Kafka, gRPC, GraphQL, etc), not only for Http. This is the reason why these Middlewares, Guards, etc are not specific to Http, but they can be used in Http as well. If you want to learn more about the engine system, please check the [Engine System documentation](/axispark/docs/category/engine-system).
