# Pipes

Pipes are a powerful feature of the engine system that allow you to transform and manipulate data when it is being injected into your engine steps. Pipes can be used to perform various operations on the data, such as validation, transformation, or formatting, before it is passed to the step.

A `Pipe` is a decorator that can be applied to a class, method, or property to specify a the transformations that will be applied to the data being injected. Pipes can be used in conjunction with parameters to create more complex and dynamic workflows. A pipe can include more than one transformation, and the transformations will be applied in the order they are defined. We will refer to these transformations as `pipe-steps`.

## Creating Custom Pipe-Steps

You can create your own custom pipe-steps by implementing the `PipeStep` interface and defining the function that will be included in the Pipe decorator. A custom pipe-step can be used to perform any transformation or validation that is not covered by the built-in pipe-steps. Here is an example of how to create a custom pipe-step.

```ts
import { ParameterDefinition, PipeStep } from '@axisparkjs/engine';
import { Injectable } from '@axisparkjs/di';

// Transformation logic
@Injectable()
export class CustomCasePipeStep implements PipeStep<string, string> {
    execute(parameter: ParameterDefinition): any {
        ...
    }
}

// Function to include in the Pipe decorator
export const Custom = () => CustomCasePipeStep;
```

Pipe-steps can also include additional parameters to customize their behavior. For example, you can create a pipe-step that accepts a parameter to specify the number of decimal places to round a number to.

```ts
import { ParameterDefinition, PipeStep } from '@axisparkjs/engine';
import { Injectable } from '@axisparkjs/di';

// Pipe-step configuration interface
export interface CustomPipeStepConfig extends PipeStepConfig {
    value: number;
}

// Transformation logic
@Injectable()
export class CustomPipeStep implements PipeStep<number, number> {
    execute(parameter: ParameterDefinition, config: CustomPipeStepConfig): any {
        ...
    }
}

// Function to include in the Pipe decorator
export const Custom = (value: number) => {
    return {
        pipeStep: CustomPipeStep,
        PipeStepConfig: { value } as CustomPipeStepConfig
    };
};
```

##  Using Pipes in Engine Steps

In any engine step, you can use the `@Pipe()` decorator to specify the pipe-steps that will be applied to the data being injected. The `@Pipe()` decorator accepts one or more pipe-step functions as arguments. Here is an example of how to use pipes in an engine step.

```ts
import { EngineStep, Pipe } from '@axisparkjs/engine';

@Pipe(NotEmpty(), Trim())
export class Example {
    @Pipe(MaxLength(10))
    async execute(@AnyParamterDecorator() @Pipe(LowerCase()) input: string): Promise<void> {
        ...
    }
}
```

In this example, for parameter `input`, the 4 pipe-steps `NotEmpty()`, `Trim()`, `MaxLength(10)`, `LowerCase()` and  will be applied in the order they are defined. The data will first be checked to ensure it is not empty, then any leading or trailing whitespace will be removed, then it will be checked to ensure it does not exceed a maximum length of 10 characters, and finally it will be converted to lowercase before being passed to the `execute` method.

> `NotEmpty()` and `Trim()` are applied to the class, so they will be applied to all parameters of any method of the class. `MaxLength(10)` is applied to the method, so it will be applied to all parameters of the method. `LowerCase()` is applied to the parameter, so it will only be applied to that specific parameter.
